# lib — ไลบรารีที่ฝังไว้ในเครื่อง

**ห้ามเปลี่ยนไปโหลดจากเน็ต** ทั้งสี่ไฟล์นี้ต้องอยู่ในโฟลเดอร์นี้เสมอ

## ทำไม

v1 โหลด Vue · SheetJS · ExcelJS · JSZip จาก cdnjs ทุกครั้งที่เปิดแอป
**ถ้าเน็ตโรงงานล่มหรือบล็อก cdnjs แอปเปิดไม่ขึ้นเลย** — ไม่ใช่ช้า ไม่ใช่บางฟีเจอร์หาย
แต่หน้าขาวสนิท ทั้งที่ข้อมูลอยู่ในเครื่องครบและไม่ต้องใช้เน็ตทำงานเลย

`plan` แก้เรื่องนี้ไปแล้วด้วยการฝัง SheetJS ไว้ในไฟล์ v2 ทำแบบเดียวกันตั้งแต่วันแรก

## ที่มา

ดึงจาก cdnjs เมื่อ 15 ส.ค. 2026 รุ่นเดียวกับที่ v1 ใช้อยู่ เพื่อไม่ให้พฤติกรรมเปลี่ยน

```
vue.global.prod.js   vue/3.4.21/vue.global.prod.min.js
xlsx.full.min.js     xlsx/0.18.5/xlsx.full.min.js
exceljs.min.js       exceljs/4.4.0/exceljs.min.js
jszip.min.js         jszip/3.10.1/jszip.min.js
```

## วิธีอัปเกรด

อย่าอัปเกรดเพราะมีรุ่นใหม่ออก อัปเกรดเมื่อมีเหตุผลเท่านั้น
แล้วต้องรัน `npm test` ให้ผ่านก่อนเสมอ — โดยเฉพาะเทสที่ออก Bin Card
เพราะหน้าตาไฟล์ที่ได้ต้องเหมือนเดิมทุกจุด เป็นเอกสารที่ลูกค้าดู
